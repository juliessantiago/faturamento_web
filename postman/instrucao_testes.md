# :pencil: Instrução dos testes automatizados no Postman + Newman 

-> Testes foram criados dentro de somente uma collection no Postman, separados por pastas. Cada pasta possui um teste diferente, tendo suas requisições e seus scripts.

-> Após a criação dos testes, a collection foi exportada para a pasta Postman, dentro do projeto de teste e executados no terminal, dentro do VSCode
